# Cisco Catalyst Center Automation

Python tools and examples for automating **Cisco Catalyst Center** and
**Software-Defined Access (SDA)** operations.

This project focuses on practical network automation workflows for
enterprise environments, including inventory discovery, fabric validation,
provisioning, and operational health checks.

> **Note:** This repository contains sanitized examples designed for
> demonstration and lab use. It does not contain production credentials,
> customer information, internal addressing, or proprietary configurations.

---

## 🎯 Project Goals

The goal of this repository is to demonstrate practical approaches to
automating Cisco Catalyst Center operations using Python and REST APIs.

Areas of focus include:

- Device and site discovery
- Network inventory
- SDA fabric validation
- Fabric role validation
- Virtual Network (VN) operations
- IP pool and Anycast Gateway workflows
- Provisioning validation
- Pre-change and post-change health checks
- API-driven network troubleshooting

---

## 🛠️ Technologies
